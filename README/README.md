# Dış Ticaret Karar Destek Sistemi

## Proje Hakkında
Bu proje, dış ticaret verilerini analiz ederek karar vericilere destek sağlamak amacıyla geliştirilmiştir. Sistem; ihracat, ithalat, dış ticaret dengesi ve ticaret hacmi göstergelerini hesaplayarak kullanıcıya anlamlı sonuçlar sunmaktadır.

## Temel Özellikler
- CSV veri yükleme
- Veri temizleme ve ön işleme
- İhracat ve ithalat analizi
- Ticaret dengesi hesaplama
- Grafik ve rapor oluşturma
- Linear Regression ve Random Forest ile tahminleme
- Karar destek önerileri üretme
- PDF raporu oluşturma

## Kullanılan Teknolojiler
- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
- ReportLab

## Çalışma Mantığı
1. Kullanıcı verileri sisteme yükler.
2. Veriler temizlenir ve analiz edilir.
3. Temel dış ticaret göstergeleri hesaplanır.
4. Tahmin modelleri ile gelecek yıllara yönelik öngörüler oluşturulur.
5. Karar destek modülü öneriler üretir.
6. Sonuçlar grafik ve raporlar halinde sunulur.

## Çıktılar
- Analiz tabloları
- Grafikler
- Tahmin sonuçları
- Karar destek önerileri
- PDF raporu
